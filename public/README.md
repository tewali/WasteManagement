# Brand assets

Drop the real brand images in this folder — the app picks them up automatically
(no code change needed) and falls back to the built-in SVG placeholders when a
file is missing:

| File | Used for |
|---|---|
| `anna.jpg` | Sidebar hero portrait + chat avatar of Anna |
| `valli-logo.png` | Company logo in the sidebar (rendered on a white chip) |

Upload via GitHub: **Add file → Upload files** on this folder (branch
`claude/waste-management-interface-4ellba`), name the files exactly as above.
